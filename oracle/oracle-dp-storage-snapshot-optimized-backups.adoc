= ストレージSnapshotで最適化されたバックアップ
:allow-uri-read: 


[role="lead"]
Oracle Snapshot Optimized Backups は、データベースをホット バックアップモードに切り替えることなく、スナップショットを使用してリカバリを実行できるポイントインタイムリカバリの方法です。

ユーザーはバックアップモードを使用せずにスナップショットから復元することもできますが、完全な復元は RECOVERY AUTOMATIC を使用した場合のみサポートされます。スナップショットの作成時刻を示すために SNAPSHOT TIME 方式を使用した不完全なリカバリ。
