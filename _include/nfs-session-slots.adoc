NFSセッションスロットは、NFSv4.XにおけるNFSv3スロットテーブルに相当するものです。デフォルト値は通常64です。180という値は、ONTAPのセッション制限と一致するため最適です。

max_session_slots パラメータの設定例：

....
# cat /etc/modprobe.d/nfsclient.conf
 options nfs max_session_slots=180
....
起動時にロードされるカーネルモジュールがこのパラメータを使用します。NFSv3のスロットテーブルパラメータとは異なり、動的ではありません。変更を有効にするには、再起動が必要です。


CAUTION: これらのパラメータを設定しないと、パフォーマンスに重大な影響を与える可能性があります。linux OSが十分なI/Oを発行していないため、パフォーマンスが著しく制限される可能性があります。
